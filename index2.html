全体の流れ

  1. 本社
    災害をkintoneに登録し、各物件の現場担当者へ「指示メール」を送ります。
  2. 現場担当者
    メールのリンクからフォームを開き、「第一報」を送ります。「受付完了メール」が自動で届きます。
  3. 担当マネージャー
    kintoneの通知を受けて報告を確認し、「確認状況」を更新します。聞きたいことがあれば「追加確認メール」を送ります。最終報を「確認済」にすると、その物件の報告書（Excel）が自動で添付されます。
  4. 現場担当者
    状況が変わるたびに「続報」を、被害が確定したら「最終報」を送ります。確認と報告を繰り返します。
  5. 本社
    全物件の最終報が確認済になったら、全体をまとめて社長へ報告し、災害を締めます。締めた災害はフォームに出なくなり、社長報告書（Excel）が自動で添付されます。

報告の3つの種類

種類送るときポイント
第一報指示メールを受けたら、期限までにわかる範囲でよい。わからない項目は「確認中」
続報状況が変わったとき、追加確認を受けたとき何回送ってもよい。間違いの訂正もこれで送る
最終報被害状況が確定したとき復旧見込日がわかれば入れる

報告は毎回新しく送ります。前に送った報告を直す必要はありません。

報告の手順

  1. 指示メールを開く件名は「【災害報告のお願い】○○（災害ID：○）」です。報告期限と、フォームで選ぶ災害名を確認します。
  2. フォームを開くメールの中のリンクを押します。ログインやパスワードは不要です。
  3. ① 災害を選ぶ右の虫眼鏡ボタンを押し、指示メールと同じ災害名を選びます。進行中の災害が1件だけのときは自動で入ります。
  4. ② 物件を選ぶ虫眼鏡ボタンを押すと物件の一覧（物件IDと物件名）が出ます。自分の物件名を押すと、物件名・所在地・指定管理者名が自動で入ります。
  5. 報告区分を選ぶ第一報・続報・最終報のどれかを選びます。
  6. 報告者の情報を入れる氏名、災害時につながる電話番号、メールアドレスです。受付完了メールと追加確認メールは、このアドレスに届きます。
  7. 被害状況を入れる書き方は下の「入力項目の書き方」を見てください。
  8. 確認して送る一番下の「確認」を押し、内容を見直してから送信します。
  9. 受付完了メールを確かめる数分以内に「【受付完了】災害報告を受け付けました」が届けば完了です。
途中で中断するとき画面右下の「一時保存」で、入力途中の内容を残せます。

届く通知

通知は担当マネージャー全員に届くので、物件名で自分の担当分を見分けます。自分の担当物件は「【災害】災害報告指示」の該当災害の「報告対象物件」テーブルで確認できます。

通知届くとき
新しいレコードの追加現場から報告が届いたとき（1件につき1回）
【至急】支援要請のある被害報告があります「本社への支援要請」が「必要」の報告が届いたとき

通知はkintone画面右上のベルと、kintoneの通知メールで受け取れます。メールでも受け取るには、kintoneの個人設定で通知メールを有効にしておきます。

確認の手順

  1. 報告を開く通知から開きます。見逃したときは「【災害】災害報告指示」で該当災害を開き、「【要対応】」一覧からたどれます。
  2. 中身を確かめる安否・建物被害・施設の利用状況・支援要請を確認します。写真があれば開いて確かめます。
  3. 確認欄を入れる「編集」を押し、一番下の「③④ 担当マネージャー確認欄」を入れます。
    • 確認状況：問題がなければ「確認済」、現場に聞きたいことがあれば「追加確認依頼中」
    • 確認者・確認日時：自分の名前と現在日時
    • 確認コメント：本社へ伝えたいことがあれば
  4. 保存する
  5. 報告状況を更新する「【災害】災害報告指示」の該当災害を開き、報告対象物件テーブルで自分の物件の「報告状況」を、届いた報告に合わせて第一報済／続報済／最終報済にします。
報告状況は自動では変わりません手順5を忘れると、本社が見る「未報告の物件数」が減りません。
最終報を確認済にすると、物件報告書が自動で作られますくわしくは物件報告書（Excel）を見てください。

追加確認の依頼

現場担当者はkintoneを見られないため、kintoneのコメントでは届きません。報告レコードからメールで送ります。

メールはPCから送ります「メールを作成する」ボタンは、スマートフォンのkintone画面には出ません。
  1. 確認状況を変える報告レコードを編集し、「確認状況」を「追加確認依頼中」にします。
  2. 質問を書いて保存する「現場への追加確認事項」に質問を具体的に書きます。この文章がそのままメールに入ります。
  3. メールを作るレコード画面の「メールを作成する」を押し、テンプレート「追加確認のお願い（報告者宛）」を選びます。
  4. 確かめて送る宛先が報告者のメールアドレスになっていることと、本文の質問を確かめて送信します。
  5. 続報を確認する現場から続報が届いたら、元の報告と続報の両方を「確認済」にします。

急ぎのときは、メールと合わせて報告者へ電話してください。電話番号は報告レコードの「報告者情報」にあります。

物件報告書（Excel）

最終報を「確認済」にして保存すると、その物件の報告書が自動で作られます。報告書は、確認欄の下の「物件報告書」欄に添付されます。

PCで保存します報告書の自動作成とボタンは、スマートフォンのkintone画面では動きません。
  1. 確認済にして保存する「確認の手順」のとおり、最終報のレコードの確認状況を「確認済」にして保存します。
  2. 数秒待つ報告書ができると、画面が自動で読み込み直されます。
  3. 添付を確かめる「物件報告書」欄にファイルが入ったことを確かめます。ファイル名は「物件報告書_災害名称_物件ID_物件名_作成日時.xlsx」です。

報告書には、最終報の内容と、第一報から最終報までの経過が入ります。自分の担当物件だけの内容です。

最終報のレコードの詳細画面には、ボタンが出ます。

途中経過の物件報告書を作成
確認済にする前に、いまの内容を報告書にしたいとき。
物件報告書を作り直して差し替え
確認済にした後で内容を直したとき。添付中のファイルは新しいものに置き換わります。
  • 第一報・続報のレコードには、報告書もボタンも出ません。
  • 同じ物件から最終報が2回届いたときは、新しいほうのレコードを確認済にします。そのレコードにも報告書が作られます。古いほうで作った報告書には「より新しい最終報があります」と表示されます。
  • 「自動作成に失敗しました」と出ても、確認状況の保存はできています。詳細画面のボタンから作り直してください。それでも失敗するときは、表示された文面を控えてkintone管理者（DX推進部）へ連絡します。

電話報告の代行入力

現場と同じフォームから、代わりに入力してください。フォームなら災害と物件を一覧から選ぶので、名前の表記がずれず、災害ごとの一覧に確実に載ります。

  1. フォームを開く災害報告フォーム
  2. ①災害と②物件を選ぶ
  3. 報告者を入れる報告者氏名には電話をくれた現場担当者の名前、電話番号にはその人の番号を入れます。
  4. メールアドレスを入れる必須です。現場担当者のアドレスがわかればそれを、わからなければ自分のアドレスを入れます。受付完了メールはこのアドレスに届きます。
  5. 備考に代行入力と書いて送る例：「14時20分 電話報告を清水が代行入力」
  6. 確認済にする届いた報告をkintoneで開き、確認状況を「確認済」にします。
kintoneに直接入力するとき災害名称は「【災害】災害報告指示」から一字一句そのままコピーします。1文字でも違うと、災害ごとの一覧に出ません。画面下部の「【使用しない】」項目は空欄のままで構いません。

注意事項

「【テンプレート】」の災害レコードは編集・削除しないこのレコードから指示メールを送ると、全物件の現場担当者に届いてしまいます。

  • 現場が入力した部分は書き換えず、訂正は現場に続報を送ってもらいます。自分の意見は「確認コメント」に書きます。

災害を登録する

  1. 【テンプレート】を開く「【災害】災害報告指示」で、災害ID「1」の「【テンプレート】」レコードを開きます。
  2. 「再利用する」を押す全15物件がセットされた新しいレコードの入力画面が開きます。【テンプレート】そのものは編集しません。
  3. 項目を入れる
    • 災害名称：年を入れた、他と重ならない名前（例：2026年 台風10号）。保存後は変えません。現場の報告とはこの名前で結びつくためです。
    • 災害種別・発生日時・対象地域
    • 指示日時と報告期限：テンプレートの日時が入っているので、必ず実際の日時に直します。
    • 指示内容：テンプレートの文面のままでよく、必要なら書き足します。
  4. 対象外の物件を外すあれば、報告対象物件テーブルの行を削除します。
  5. 保存する

指示メールを送る

登録から数分たってから送りますフォームに新しい災害が出るまで最大1分かかります。メールはPCのkintoneから送ります。
  1. 「メールを作成する」を押す保存した災害レコードの画面で押します（左側の赤枠）。
  2. テンプレートを選ぶ「災害報告の指示（現場宛）」を選びます。
  3. 確かめて送る宛先に対象物件の現場担当者のアドレスが入っていること、本文の災害名・期限が正しいことを確かめて送信します。
  4. 送信日時を確かめるレコードの「指示メール送信日時」が自動で記録されます。
【テンプレート】レコードからは絶対に送らない送ると、全物件の現場担当者に指示メールが届いてしまいます。

報告を待つ間

  • 「未報告の物件数」と「【要対応】」一覧で進み具合を見ます。
  • 支援要請が「必要」の報告が届くと、担当マネージャーに【至急】の通知が届きます。本社としての対応は担当マネージャーと相談して決めます。

締める前の確認

災害レコードの「⑤⑥ 最終確認・社長報告」欄を入れる前に、次の3つを確かめます。チェックはこの画面の中だけのものです。

同じ物件の最終報が2行ある場合（訂正の再送など）は、報告日時の新しいほうを正とします。

総括コメントの書き方

社長がこのコメントだけで全体をつかめるよう、次の順で書きます。

  1. 災害の概要：災害名称、種別、発生日時、対象地域
  2. 報告の状況：対象物件数と、最終報がそろった日時
  3. 人的被害：有無と人数。ある場合は物件名と内容
  4. 建物被害：「被害なし」「軽微」「一部損壊以上」それぞれの物件数。一部損壊以上は物件名も
  5. 施設の利用：一部・全面利用不可の物件名と復旧見込日
  6. 支援要請と本社の対応
  7. 被害見込額：わかる範囲の合計（概算）
  8. 今後の対応：復旧の段取りと、次に報告する予定

支援要請と被害見込額は最終報の一覧に出ないため、「現場からの報告」や各報告レコードを開いて確認します。締める前に「途中経過の報告書を作成」（社長報告書）で報告書を作ると、総括シートでまとめて確認できます。

記入例（架空の内容です）：

2026年 台風10号（10/12発生、埼玉・東京）。対象15物件の最終報が10/14 15時にそろいました。人的被害はありません。建物は被害なし12件、軽微2件、一部損壊1件（○○体育館：屋根の一部破損）。○○体育館はアリーナを10/20まで利用中止します。支援要請は1件（同館の養生資材）で、10/13に手配済みです。被害見込額は概算120万円。修繕業者の見積もりが出しだい追って報告します。

締めて、社長へ伝える

  1. 締めの欄を入れて保存する「報告先（社長）」「最終確認者」「最終確認日時」を入れて保存します。保存すると、数秒で社長報告書（Excel）が作られ、総括コメントの下の「社長報告書」欄に添付されます。
  2. 社長へ伝える保存しても社長には何も届きません。次のどちらかで伝えます。
    • レコードのコメントで社長をメンションし、「添付の社長報告書をご確認ください」と添える（社長にkintoneの通知が届き、記録もレコードに残る）
    • 口頭やメールで伝え、レコードのURLを添える
途中経過の報告では、最終確認日時を入れない入れるとフォームから災害が消え、現場が続報・最終報を送れなくなります。途中経過はコメントなどで伝え、総括コメントに書くなら「10/13 12時時点」のように時点を明記します。Excelで渡したいときは、社長報告書の「途中経過の報告書を作成」を使います。
  • 締めると、1分ほどでフォームの①から消えます。
  • 締めた後に訂正や追加の報告が必要になったら、最終確認日時を空にして保存すれば再びフォームに出ます。受け付けたら日時を入れ直し、総括コメントも更新します。社長報告書は自動では作り直されないので、下のボタンで作り直します。

社長報告書（Excel）

最終確認日時を入れて保存すると、社長報告書が自動で作られます。保存してから数秒で画面が読み込み直され、「社長報告書」欄にファイルが入ります。ファイル名は「社長報告書_災害名称_作成日時.xlsx」です。
